# Rock Paper Scissors (UI Version)

Built as part of The Odin Project Foundations 
curriculum. An upgrade of the original 
console-based version — same game logic, now 
with a working browser UI.

## About

A Rock Paper Scissors game playable in the 
browser. The player clicks a button to make 
their choice each round. First to 5 wins.

## What I built

- Button-based UI replacing the original prompt
- Round-by-round result and score display
- DOM manipulation to render results dynamically
- Game end detection with input disabled after 
  a winner is declared

## What I learned

- Event listeners on NodeLists using forEach
- Why while loops and click events don't mix —
  loops block the thread, preventing any clicks 
  from registering
- Scope as a real debugging problem, not a 
  theoretical one
- append() with multiple arguments over 
  repeated appendChild() calls
- button.disabled to control UI state
- Reworking existing code is normal — being 
  mentally ready for it matters
- Taking a break when stuck is a legitimate 
  debugging strategy, not giving up
